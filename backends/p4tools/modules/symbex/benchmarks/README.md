# Symbex Benchmarks
The [`backends\p4tools\modules\symbex\benchmarks` folder](https://github.com/p4lang/p4c/tree/main/backends/p4tools/modules/symbex/benchmarks) contains utility scripts to benchmark Symbex. `test_coverage.py` measures coverage of various path selection strategies. `plot.py` creates plots of the results.
